# Dashboard Plan

## Dashboard Title

Student Academic Performance Analytics

## Objective

Provide an interactive overview of student academic performance and identify patterns across subjects, classes, and selected demographic groups.

## Target Audience

- School administrators
- Teachers
- Education managers
- Data analysts
- Recruiters/employers reviewing the portfolio

## Primary KPIs

1. Total Students
2. Average Final Percentage
3. Pass Rate
4. Average Math Score
5. Average Science Score
6. Average English Score

## Primary Visuals

1. Student Distribution by Performance Level
2. Average Score by Subject
3. Distribution of Final Percentage
4. Average Final Percentage by Class
5. Average Final Percentage by Parental Education
6. Average Final Percentage by Gender

## Slicers

- Class
- Gender
- Parental Education
- Internet Access

## Design Principles

- Clean and professional layout
- Consistent color palette
- Minimal visual clutter
- Clear titles and labels
- Consistent spacing and alignment
- Interactive filtering
- Evidence-based storytelling
- Avoid implying causation from descriptive analysis

## Key Analytical Message

The available dataset does not provide sufficient evidence to identify a single dominant driver of student success. The dashboard therefore focuses on describing performance patterns and differences rather than making causal claims.
