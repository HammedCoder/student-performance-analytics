# 2.7 Analytical Workflow

Our workflow will follow these stages:

1. Define the business problem.
2. Understand the dataset.
3. Assess data quality.
4. Clean and transform the data.
5. Perform exploratory data analysis.
6. Write SQL queries to answer business questions.
7. Define and calculate KPIs.
8. Design dashboard wireframes.
9. Build the Power BI dashboard.
10. Interpret findings.
11. Develop recommendations.
12. Prepare executive reporting and presentation.

# 2.8 Risks and Mitigation

| Risk                                    | Mitigation                                                                      |
| --------------------------------------- | ------------------------------------------------------------------------------- |
| Missing or inconsistent data            | Validate and clean data before analysis                                         |
| Incorrect KPI definitions               | Align KPIs with business objectives                                             |
| Dashboard clutter                       | Prioritize simplicity and user experience                                       |
| Circular analysis using derived metrics | Treat `Final_Percentage` as an outcome rather than a predictor when appropriate |
| Poor documentation                      | Document each phase as it is completed                                          |
