# Improving Student Academic Performance Through Data Analytics

## Identifying the Key Drivers of Student Success

### Project Overview

This project analyzes student academic performance data to identify the key factors associated with student success.

The project follows a complete data analytics workflow, from business understanding and data preparation to exploratory analysis, SQL analysis, visualization, and interactive dashboard development.

The final outcome is a Power BI dashboard that transforms student data into actionable insights that can support teachers, school administrators, and other educational stakeholders in making evidence-based decisions.

---

## Problem Statement

Educational institutions collect substantial amounts of student information, but the data is not always effectively analyzed to understand why some students perform better than others.

Without meaningful analysis, teachers and school administrators may find it difficult to identify students who require additional support or understand the factors associated with stronger academic outcomes.

This project addresses this problem by analyzing student performance data and investigating the relationship between academic results and factors such as:

* Attendance
* Study hours
* Previous academic performance
* Subject scores
* Class level
* Age
* Gender
* Parental education

---

## Project Objectives

The main objectives of this project are to:

1. Clean and prepare the student performance dataset for analysis.
2. Assess the quality and reliability of the available data.
3. Explore patterns and distributions in student academic performance.
4. Analyze relationships between student characteristics and final performance.
5. Use SQL to generate meaningful analytical insights.
6. Develop an interactive Power BI dashboard.
7. Identify the key drivers associated with academic success.
8. Provide actionable recommendations for educational stakeholders.

---

## Key Questions

The analysis seeks to answer questions such as:

* What is the overall academic performance of the students?
* What percentage of students meet the defined pass criteria?
* Does attendance have a relationship with academic performance?
* Does study time influence final scores?
* How strongly does previous-year performance relate to final performance?
* Which subject has the highest average score?
* How does performance vary across classes?
* Does parental education appear to be associated with student performance?
* Which student groups demonstrate the strongest academic outcomes?

## Dataset

The dataset contains student academic and demographic information.

Key variables include:

| Variable            | Description                          |
| ------------------- | ------------------------------------ |
| Age                 | Student age                          |
| Gender              | Student gender                       |
| Class               | Student class level                  |
| Study_Hours_Per_Day | Average daily study hours            |
| Attendance          | Student attendance percentage        |
| Previous_year_score | Previous academic score              |
| Math_Score          | Mathematics score                    |
| English_Score       | English score                        |
| Science_Score       | Science score                        |
| Parental_Education  | Parent/guardian education level      |
| Final_percent       | Calculated final academic percentage |

### Dataset Limitations

The dataset contains only three academic subjects: Mathematics, English, and Science.

It does not contain variables such as socioeconomic status, school resources, teacher characteristics, learning disabilities, family income, or detailed behavioural information.

These limitations are considered when interpreting the results.

## Key Findings

The analysis indicates that:

* Attendance is positively associated with academic performance.
* Students who spend more time studying tend to achieve stronger final results.
* Previous-year performance has a strong relationship with final academic performance.
* Academic performance varies across class levels.
* Students with stronger performance across individual subjects generally achieve higher final percentages.

The dashboard allows these patterns to be explored interactively using filters and visualizations.

## Recommendations

Based on the analysis, schools could consider:

1. Monitoring student attendance more closely.
2. Providing additional academic support for students with consistently low performance.
3. Encouraging structured study routines.
4. Using previous academic performance to identify students who may require early intervention.
5. Using data dashboards to monitor academic performance continuously rather than relying only on end-of-term results.
